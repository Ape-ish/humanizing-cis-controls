# Documentation Folder (`/docs`)

This folder powers the GitHub Pages site for **Humanizing the CIS Controls**.

### Site Overview
- Markdown files in `/docs` are auto-rendered into HTML by GitHub Pages.
- The homepage of the site is `docs/index.md`, which links to the rest of the content.
- Each subfolder (e.g., `phase1/`, `nist/`, `resources/`) contains topic-specific markdown files.

### How to Update the Site
1. Edit or add `.md` files inside the `/docs` folder or its subfolders.
2. Commit the changes to the `main` branch.
3. GitHub Pages will automatically rebuild the site.

📁 This folder is not used for code — only for rendered site content.
